# e-Sumbong / CommunityPulse (Mabalacat City)
Hybrid Emergency & Civic Incident Reporting Portal with Smart Routing, Waze-Style Upvotes, and First-to-Accept Dispatch.

## Tech Stack
- **Frontend:** HTML5, CSS, Leaflet.js (Hosted on Vercel)
- **Backend:** Vanilla PHP 8 (PDO)
- **Database:** MySQL (XAMPP Local) / TiDB (Cloud Production)
- **Integrations:** Brevo API (Email OTP & Notifications)

## Local Setup (XAMPP)
1. I-clone ang repository na ito sa iyong `htdocs/` folder.
2. I-import ang `database.sql` sa iyong phpMyAdmin.
3. Ituro ang iyong DocumentRoot sa `/public` folder.
